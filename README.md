# Задание

Используя пример лекции Доработать TB adapter_tb.sv в части:
- Передать данные: MSG = 'hDECAFBAD.
- Предусмотреть управление сигналом valid_i  от передатчика и credit_i от приемника. Таким образом чтобы кол-во кредитов в переходнике накапливалось.


Доработки должны поддерживать возможность передачи сообщений разной длины.

При успешном окончании теста в консоль должна быть выдан статус
```
PASSED
```
в противном случае 
```
FAILED
```


## Запуск тестов с использование Verilator
```
make run
```
